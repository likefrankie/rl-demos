# RL demos

Interactive demonstrations for the Reinforcement Learning course. Each demo replays precomputed data (in `data/`), so
nothing is trained or solved while it runs.

- **Ice Cream Scoop**: Value Iteration
- **1D Gridworld**: Value Iteration
- **2D Gridworld**: Value Iteration
- **3D Gridworld**: Value Iteration

Run locally: `pip install -r requirements.txt`, then `streamlit run Home.py`.

This repository is generated by `demos/streamlit_deploy.py` in the course repository; do not edit it by hand.
